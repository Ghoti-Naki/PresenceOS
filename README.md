# PresenceOS

A full-stack personal portfolio website with a built-in CMS admin panel. Manage your projects and read contact messages through a secure admin interface — no redeployment required.

**Live demo:** _add your URL after deploying_

---

## Features

- **Public portfolio** — Hero, About (skills), Projects, and Contact sections
- **Dark / light mode** — persistent theme toggle
- **Scroll animations** — Framer Motion `whileInView` on all sections
- **Contact form** — submissions saved to database and emailed via Resend
- **Admin panel** — JWT-authenticated CMS at `/admin`
  - Create, edit, delete projects
  - Read and manage contact messages
  - Publish / unpublish projects
- **SEO ready** — Open Graph, Twitter card, `robots.txt`, `sitemap.xml`
- **ISR** — homepage revalidates every 60 s without redeployment

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 15 (App Router, TypeScript strict) |
| Styling | Tailwind CSS v4 + shadcn/ui (nova/Base UI preset) |
| Animations | Framer Motion v12 |
| Database | PostgreSQL via [Neon](https://neon.tech) |
| ORM | Drizzle ORM |
| Auth | Custom JWT in `httpOnly` cookies (`jose`) |
| Email | [Resend](https://resend.com) |
| Validation | Zod v4 |
| Deployment | Vercel |

## Local Setup

### 1. Clone and install

```bash
git clone https://github.com/your-username/presenceos.git
cd presenceos
npm install
```

### 2. Configure environment variables

```bash
cp .env.example .env.local
```

Open `.env.local` and fill in every value — see [Environment Variables](#environment-variables) below.

### 3. Set up the database

```bash
npm run db:generate   # generate SQL migration files
npm run db:migrate    # apply migrations to Neon
npm run db:seed       # insert 3 sample projects
```

### 4. Generate your admin password hash

```bash
npm run hash-password -- yourpassword
# Prints: ADMIN_PASSWORD_HASH=abc123...:def456...
# Paste that line into .env.local
```

### 5. Start the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — public site.
Open [http://localhost:3000/admin/login](http://localhost:3000/admin/login) — admin panel.

## Environment Variables

Copy `.env.example` to `.env.local` and set all values:

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | Neon PostgreSQL connection string |
| `JWT_SECRET` | Random 32+ char string — `openssl rand -base64 32` |
| `ADMIN_USERNAME` | Your admin login username |
| `ADMIN_PASSWORD_HASH` | Generated by `npm run hash-password -- <password>` |
| `RESEND_API_KEY` | From [resend.com/api-keys](https://resend.com/api-keys) |
| `RESEND_FROM_EMAIL` | Sender address (use `onboarding@resend.dev` until you verify a domain) |
| `CONTACT_EMAIL_TO` | Email that receives contact form submissions |
| `NEXT_PUBLIC_SITE_URL` | Your deployed URL, e.g. `https://yourname.vercel.app` |

## API Reference

### Public

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/projects` | List published projects |
| `POST` | `/api/messages` | Submit contact form |

### Auth

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/login` | Sign in — sets JWT cookie |
| `POST` | `/api/auth/logout` | Clear JWT cookie |
| `GET` | `/api/auth/me` | Return current session |

### Admin (JWT required)

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/admin/projects` | List all projects (incl. drafts) |
| `POST` | `/api/admin/projects` | Create project |
| `PUT` | `/api/admin/projects/[id]` | Update project |
| `DELETE` | `/api/admin/projects/[id]` | Delete project |
| `GET` | `/api/admin/messages` | List all messages |
| `PATCH` | `/api/admin/messages/[id]/read` | Mark message as read |
| `DELETE` | `/api/admin/messages/[id]` | Delete message |

## Customisation

### Personal information

Edit `src/config/site.ts`:

```ts
export const siteConfig = {
  name: "Your Name",
  title: "Your Role",
  description: "Your meta description",
  url: "https://yourdomain.com",
  bio: "Your bio paragraph...",
  links: {
    github: "https://github.com/yourhandle",
    linkedin: "https://linkedin.com/in/yourhandle",
    instagram: "https://instagram.com/yourhandle",
  },
};
```

### Skills

Edit `src/config/skills.ts`. Each skill has a `name` and `category`. Categories group automatically in the About section.

### Adding a project via admin

1. Log in at `/admin/login`
2. Go to **Projects → New Project**
3. Fill in title, description, URLs, tags
4. Check **Published** to make it visible on the homepage
5. Save — the homepage updates within 60 seconds (ISR)

## Database Schema

**`projects`**

| Column | Type | Notes |
|--------|------|-------|
| `id` | UUID | Primary key |
| `title` | text | Required |
| `slug` | text | Unique, URL-safe, auto-generated from title |
| `description` | text | Short summary shown on card |
| `content` | text | Optional long-form write-up |
| `image_url` | text | Optional cover image URL |
| `github_url` | text | Optional |
| `live_url` | text | Optional |
| `tags` | text[] | Array of tag strings |
| `is_featured` | boolean | |
| `sort_order` | integer | Controls display order |
| `published_at` | timestamptz | null = draft |
| `created_at` | timestamptz | Auto |
| `updated_at` | timestamptz | Set manually on update |

**`messages`**

| Column | Type | Notes |
|--------|------|-------|
| `id` | UUID | Primary key |
| `name` | text | Sender name |
| `email` | text | Sender email |
| `subject` | text | |
| `body` | text | Message content |
| `is_read` | boolean | Default false |
| `created_at` | timestamptz | Auto |

## Deployment (Vercel)

1. Push the repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo
3. Set all [environment variables](#environment-variables) in **Settings → Environment Variables**
4. Set **Node.js version to 22** in **Settings → General**
5. Click **Deploy**

After deployment, update `NEXT_PUBLIC_SITE_URL` to your live URL and trigger a redeploy.
